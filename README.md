# Agentic Platform Roadmap

A phase-based maturity model for an agentic AI platform: Foundation, Orchestration, Governance, Autonomous action, and Scale, plus 8 cross-cutting infrastructure modules (Knowledge and retrieval, Tools and integrations, Memory, Model routing, Guardrails, Observability, Access and tenancy, FinOps) that mature in parallel across all five phases.

Vendor-neutral by design: describes capabilities functionally rather than naming any specific product.

Open `index.html` in a browser to view.
